Dubai community rental yields: June 2026
=======================================

Open documentation and the owned dataHabibi June 2026 CSV snapshot.
The dataset is published at:
https://www.data.gouv.fr/datasets/dubai-community-rental-yields-june-2026-datahabibi

Source: https://datahabibi.ae/

(CC BY 4.0). See LICENSE.md.

Documentation source: index.rst. Build configuration: .readthedocs.yaml.
This repository documents a released dataset; it does not provide a public API
or the source code of dataHabibi's commercial platform.
